## 7. 手工探索建议

自动化之外，面试前建议手工点一遍：

1. 用错误密码连续登录，看提示是否一致；
2. 在购物车把数量改成 0 或负数，看前端限制和后端校验；
3. 同一账号开两个浏览器窗口，一个加购、一个删除，观察数据是否一致；
4. 下单后立刻刷新订单页，确认不是前端假数据；
5. 用不同窗口尺寸看布局是否错乱（当前自动化只覆盖桌面 1440×960）。
