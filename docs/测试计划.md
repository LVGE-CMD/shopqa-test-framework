# ShopQA 测试计划

## 1. 项目背景

ShopLite 是一个迷你电商系统，包含登录、商品、购物车、优惠券、下单、订单查询等核心链路。本项目为它建立一套可持续执行的自动化测试框架，用于替代重复的手工回归，并在每次代码变更后快速发现功能退化。

## 2. 测试目标

1. 验证核心业务链路可用：登录 → 加购 → 结算 → 下单 → 查订单。
2. 验证关键业务规则：库存、优惠券门槛、金额计算、用户数据隔离。
3. 建立可重复执行的接口 + UI 自动化回归集，接入 CI。
4. 形成测试计划、用例、缺陷模板、测试报告等完整交付物。
5. 让测试结果可读：失败能看到请求、响应、截图、页面 HTML 和日志。

## 3. 测试范围

### 3.1 范围内

| 模块 | 测试内容 |
|---|---|
| 认证 | 注册、登录、token、未登录/伪造 token、用户隔离 |
| 商品 | 列表、详情、搜索、大小写、空结果、404 |
| 购物车 | 加入、重复加入、修改数量、删除、库存上限、参数校验 |
| 订单 | 下单、空购物车、优惠券、订单列表、订单详情、越权、库存扣减 |
| Web UI | 登录成功/失败、访问控制、搜索、加购、改数量、移除、结算、订单历史 |
| 数据 | 订单/明细落库、库存变化、密码哈希、购物车数据隔离 |
| 契约 | 登录、用户、商品、购物车、订单、错误响应结构 |

### 3.2 范围外

- 真实支付、退款、发票、物流；
- 并发扣库存、分布式事务、消息队列；
- 性能、压力、稳定性测试；
- 安全渗透、越权漏洞的深度利用；
- 多浏览器兼容性矩阵（当前只覆盖 Chromium/Edge）；
- 移动端、小程序。

范围外不代表不重要，而是当前版本先保证核心回归链路可落地。

## 4. 测试策略

采用“接口为主、UI 为辅、数据库兜底”的分层策略。

```text
            少量 UI 用例
          （关键用户旅程）
        --------------------
          较多接口用例
      （业务规则、边界、异常）
    --------------------------
        数据库 / 契约断言
      （数据真的写对了吗）
```

原因：

- 接口执行快、稳定、定位准，适合覆盖大量规则和异常分支；
- UI 用例只覆盖用户真正关心的关键路径，避免把测试金字塔倒过来；
- 数据库断言防止“接口返回成功但数据没落库”的假通过；
- JSON Schema 防止接口字段类型/必填项悄悄变化。

## 5. 测试环境

| 项 | 值 |
|---|---|
| 操作系统 | Windows 11 |
| Python | 3.12 |
| 被测服务 | FastAPI + Uvicorn，本地随机端口 |
| 数据库 | SQLite，测试会话临时文件 |
| 浏览器 | 本机 Edge（Playwright channel=msedge），CI 用 Chromium |
| 报告 | Allure |
| CI | GitHub Actions，ubuntu-latest |

测试默认不依赖外网。`SHOPLITE_BASE_URL` 可以指向已部署环境，此时跳过本地服务和数据库断言。

## 6. 准入与准出

### 准入

- 依赖安装完成，`pytest --collect-only` 能正常收集；
- ShopLite 能启动，`/health` 返回 200；
- 测试数据可自动创建，不依赖手工准备。

### 准出

- 全量用例通过率 100%；
- 冒烟用例全部通过；
- 失败用例有明确原因，不允许“重跑就过”长期存在；
- Allure 报告可打开，失败附件完整；
- 新增业务规则有对应用例或明确记录不测原因。

## 7. 进度安排（示例）

| 阶段 | 产出 |
|---|---|
| 第 1 天 | 梳理业务流程、识别风险、写测试计划 |

## 8. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 公开 Demo 站点不稳定 | 本地环境跑不起来 | 自带本地被测系统，不依赖外网 |
| UI 选择器随页面改版失效 | UI 用例批量失败 | 统一 `data-testid`，选择器集中到 Page Object |
| 用例之间数据污染 | 偶发失败、难复现 | 每用例独立用户；会话级临时数据库 |
| 浏览器/驱动版本不匹配 | 启动失败 | Playwright 自带协议；优先用 channel=msedge，CI 装 Chromium |
| 只断言接口不看数据库 | 假通过 | 订单、明细、库存、密码哈希增加数据库断言 |
| 用例执行慢 | 回归成本高 | 接口为主；后续接 xdist 并行和 CI 分片 |
