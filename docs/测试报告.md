## 4. 覆盖情况

### 4.1 业务链路

```text
注册 / 登录 / 鉴权
  → 商品列表 / 详情 / 搜索
  → 加入购物车 / 修改数量 / 删除 / 库存上限
  → 优惠券门槛 / 下单 / 金额计算
  → 订单列表 / 订单详情 / 用户隔离
  → 数据库订单、明细、库存校验
```

### 4.2 测试类型

| 类型 | 覆盖 |
|---|---|
| 正常流 | 登录、加购、下单、查订单 |
| 异常流 | 密码错误、未登录、伪造 token、空购物车、商品不存在 |
| 边界值 | 密码 7/8 位、数量 0/1/99/100、优惠券刚好 ¥100 |
| 权限 | 双用户购物车隔离、订单越权、改 URL 越权 |
| 数据 | 密码哈希、订单落库、明细落库、库存扣减 |
| 契约 | 登录、用户、商品、购物车、订单、错误响应 |

## 5. 缺陷与风险

本次全量执行无失败用例，没有发现阻断性问题。

仍需注意：

1. 当前是单机 SQLite，未覆盖并发下单和库存竞争；
2. UI 只覆盖 Chromium/Edge，未做多浏览器矩阵；
3. 未做性能、安全测试；
4. 测试数据为本地种子数据，不代表真实生产数据分布。

## 6. 结论

核心业务链路自动化回归通过，可以用于日常提交前自测和 CI 回归。
